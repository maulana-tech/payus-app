# Payus

Payments on PayPal that a team of agents can operate, where every agent
proposes and a deterministic Guardian decides.

These are the working documents:

- **[Setting it up](setup.md)** — what to install, which keys to get, and
  how to deploy it.
- **[Accepting payments](api.md)** — the widget, the checkout API, signed
  webhooks and the `@payus/js` library.
- **[The plan](plan.md)** — what was built, in what order, and the
  decisions taken along the way. Written as it happened.

The repository's own [README](../README.md) is the short version, and
`CLAUDE.md` at the root is the map for anyone (or anything) changing the
code.
